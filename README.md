Entry for the make.fun bounty "The Robot Vacuum's Best Excuse": one line, at most 140 characters, giving the funniest excuse a robot vacuum could offer for missing a spot. A judge playing a tired homeowner picks the funnier line in pairs.

## The entry

> I leave one crumb behind every clean so you still feel useful sweeping it up yourself.

(86 characters)

## How it works

`main.py` (stdlib only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, falling back to the script directory when the variable is unset. Run it with:

```sh
python3 main.py
```
